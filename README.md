# The Impossible Hotel

An original dark Omarchy theme from a hotel with recursive elevators and corridors that refuse geometry: midnight burgundy, brass, and lamplight.

![The Impossible Hotel desktop preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/leaflessbranch/omarchy-the-impossible-hotel-theme.git
```

Switch between the two included wallpapers with `omarchy theme bg next`. Update all Git-installed themes with `omarchy theme update`, or remove this one with `omarchy theme remove the-impossible-hotel`.

Requires a current Omarchy installation. Developed and tested with Omarchy 4.0.0-1.

## Included

- Complete dark palette generated through `colors.toml`
- Two original 16:9 wallpapers
- Coordinated Omarchy lock-screen colors
- `Yaru-red-dark` icon selection

Part of [Omarchy Dreamscapes](https://github.com/leaflessbranch/omarchy-dreamscapes), a ten-theme surreal desktop collection.
